# Amazon Sales Performance Analytics Dashboard

## Project Overview
This project is an interactive Power BI dashboard developed to analyze Amazon sales performance. It provides insights into sales trends, category performance, regional performance, channel performance, and key business KPIs.

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Key Features
- Data Cleaning using Power Query
- KPI Cards
- Monthly Sales Trend Analysis
- Sales by Category
- Sales by Region
- Sales by Channel
- Previous Year Sales Analysis
- Year-over-Year (YoY) Growth Analysis
- Interactive Slicers (Year, Region, Category, Channel)

## Key Performance Indicators (KPIs)
- Total Sales Amount
- Total Orders
- Total Quantity
- Average Order Value
- Previous Year Sales
- YoY Growth %
